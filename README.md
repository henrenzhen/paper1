# paper1

Research code for next ATT&CK technique prediction through the fusion of LLM-derived semantic information and sequential transition models.

## Repository scope

This repository contains source code, tests, experiment configuration, and research documentation. Large datasets, model checkpoints, generated reasoning caches, per-sample predictions, logs, and third-party raw repositories are intentionally excluded from Git.

The current reproducibility audit and execution-gate status are documented in:

- `experiments/INVENTORY.md`
- `experiments/GATE_STATUS.json`
- `experiments/ARTIFACT_CONTRACT.md`

## Important status

The Phase 0 inventory found incomplete LLM reasoning caches, so the controlled experiment pipeline is stopped at T0.1 pending a human decision. See `experiments/INVENTORY.md` for the evidence and exact coverage counts.

## Data and artifacts

Files excluded by `.gitignore` must be restored from their original sources or generated by the corresponding scripts. Do not treat the absence of checkpoints and generated prediction files in this repository as evidence that the published results have been reproduced.
