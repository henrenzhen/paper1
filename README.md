# paper1

Research code for next ATT&CK technique prediction through the fusion of LLM-derived semantic information and sequential transition models.

## Repository scope

This repository contains source code, tests, experiment configuration, research documentation, processed CSV datasets, and the original CoT reasoning caches used by the current experiments. Model checkpoints, logs, result directories, and large third-party raw repositories remain excluded from Git.

The current reproducibility audit and execution-gate status are documented in:

- `experiments/INVENTORY.md`
- `experiments/GATE_STATUS.json`
- `experiments/ARTIFACT_CONTRACT.md`
- `DATASET_MANIFEST.md`

## Important status

The Phase 0 inventory found incomplete LLM reasoning caches, so the controlled experiment pipeline is stopped at T0.1 pending a human decision. See `experiments/INVENTORY.md` for the evidence and exact coverage counts.

## Data and artifacts

Versioned CSV files are stored under `project/data`, `project/data_v2/core`, and `project/data_v2/micro_state`. Files still excluded by `.gitignore` must be restored from their original sources or generated by the corresponding scripts. Do not treat the absence of checkpoints and non-CSV generated prediction files as evidence that the published results have been reproduced.
