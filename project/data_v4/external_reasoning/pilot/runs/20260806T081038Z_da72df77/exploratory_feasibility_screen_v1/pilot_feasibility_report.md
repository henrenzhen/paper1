# 30 条试点可行性筛查报告

> **探索性、解盲、非确认性。** 本目录含 true label，严禁交给 groundedness 盲审者。该筛查不能替代人工 groundedness 门，也不能证明 B1 原论文实现成立。

## 结论

现有 30 条显示出**值得继续全量实验的初步语义信号**，但样本太小，不能得出方法已验证的结论。

- LLM 直接排名 B0：Top-1 `3/30`，Hit@5 `7/30`。
- 频率先验 A0：Top-1 `1/30`，Hit@5 `3/30`。
- 转移主干 A：Top-1 `0/30`，Hit@5 `2/30`。
- 排名融合 B2：Top-1 `2/30`，Hit@5 `7/30`。

B0 相对 A0 的逐样本配对结果为：Top-1 `3 胜 / 1 负 / 26 平`，Hit@5 `4 胜 / 0 负 / 26 平`。方向为正，但只有 30 条，不能宣称统计显著或跨来源稳定。

## 能说明什么

1. DeepSeek 返回的五个候选并非完全随机：B0 在 30 条中比 A0 多 2 个 Top-1、多 4 个 Hit@5。
2. 初步信号主要来自 Attack Flow 和 Stockpile；CTID 只有一个 Hit@5、没有 Top-1，因此尚不能声称跨三个来源稳定。
3. B2 保留了 B0 的 7 个 Hit@5，但 Top-1 从 3 个降到 2 个；现有 30 条没有证明融合优于 LLM 直接排名。
4. 当前数据不能检验 B1。每个外折只有 20 条训练 reasoning，拟合 184 类 probe 没有解释价值。

## 决策含义

从“是否值得花几元完成剩余生成”的角度，结果支持继续：语义直接排名相对 A/A0 有一致的 Hit@5 正增量，继续实验具有信息价值。

从“方法是否已经可行”的角度，答案是否定的：Top-1 只有 3 次命中、CTID 为 0，且 30 条已成为开发/筛查样本。最终判断仍需未用于本筛查的剩余 800 条及完整 B0/B1/B2/C1/C2/D 对照。
