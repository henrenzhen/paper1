# GSAD / ATT&CK 下一技术预测迭代日志（简版）

更新日期：2026-07-30  
原则：每轮只保留可复现的结论；失败方法不进入最终主张；锁定测试只允许使用一次。

| 轮次 | 方法 | 最小实验结论 | 决策 |
|---|---|---|---|
| 1 | GSAD-Core / GSAD-Shift | 同成本覆盖率下降 8.240 个百分点；exact 输出覆盖率为 0；学习路由器也无法找到可接受样本 | 淘汰集合预测主线 |
| 2 | RACER（SAR-CTW + MC-RCU） | 开发集 Top-1 有正增益，但 MRR 未过预注册门槛 | 仅保留开发候选 |
| 3 | RACER 锁定测试 | Top-1 -0.114 个百分点，95% CI [-2.715, 2.081]；MRR -0.0100；Hit@5 亦下降 | 一次性锁定测试失败，不再重跑或调参 |
| 4 | MRCT / QMR-CT | SIM 开发集有正增益，但 Stockpile 或 Attack Flow 外部域出现负向结果 | 淘汰跨域主张 |
| 5 | SC-MRGR / TGER | 图残差整体分别明显负向或仅微弱正向；未证明图结构相对强 Markov 基线有稳定增量 | 淘汰图残差主线 |
| 6 | QSMR v5 | SIM 五折 root-disjoint OOF：Top-1 +3.425 个百分点，MRR +0.0208，置信区间为正 | 证明机制在单一来源内有效，但暂不作跨域结论 |
| 7 | 公平多来源复核 | 用同等强度的域/根平衡 Markov 基线后，QSMR 跨域平均 Top-1 和 MRR 转负 | 撤回 QSMR 的跨域算法创新主张 |
| 8 | Dwell-conditioned / raw multi-resolution / nested selector | 相对强基线增量不显著，或跨域平均为负 | 淘汰 |
| 9 | support-tempered domain weights | 事后选择的小幂次看似有效，但嵌套的仅源域选择器不能复现该选择 | 判定为开发域过拟合，撤回 |
| 10 | 非零部分池化（kappa > 0） | 相对简单的 kappa=0 等域估计更差；leave-one-domain prior 版本也未通过 Top-1 门槛 | 撤回收缩创新 |
| 11 | DR-VOM（kappa=0） | 四源完整 LODO 中，各域 Top-1/MRR 点估计均非负；宏平均 Top-1 +1.817 个百分点、MRR +0.0180 | 最终保留候选，但尚未达到“投稿就绪”门槛 |

## 最终门槛复核

- 通过：四个留一来源的 Top-1 与 MRR 点估计方向均为正。
- 部分通过：SIM、Attack Flow 的 Top-1 根级 bootstrap 区间下界为正；CTID 的 MRR 区间下界为正。
- 未通过：跨四域聚合区间仍跨 0（Top-1 下界 -0.376 个百分点；MRR 下界 -0.00228）。
- 未通过：留出 SIM 时 Hit@5 下降 3.268 个百分点，违反候选集合“无伤害”要求。
- 未通过：四个外部来源已经参与方法迭代，不能再被称为全新锁定确认集。

因此，DR-VOM 是当前最可信、机制明确的有效方向，但不是已经足以保证 SCI 二区录用的完成稿。下一步必须在新的、一次性锁定来源上复核，并补充概率校准、worst-source 与更强基线。
